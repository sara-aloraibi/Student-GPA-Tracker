# Student GPA Tracker
A lightweight Java application designed to log academic courses, track earned credits, and calculate real-time cumulative Grade Point Averages (GPA).
## Features
- **Course Management:** Record course codes, titles, credit hours, and earned grade points.
- **Automated GPA Calculation:** Weighted GPA logic based on total quality points and credit counts.
- **Input Resilience:** Handles numeric parsing errors for seamless user input.
- **Clean Architecture:** Separated domain model (`Course`), calculation engine (`GPACalculator`), and UI launcher.
## Tech Stack
- **Language:** Java 17+
- **IDE:** IntelliJ IDEA
- **Concepts:** Object-Oriented Programming (OOP), Arithmetic Logic, Collections (`ArrayList`), Input Validation
## How to Run
1. Clone or download the repository.
2. Open the project in **IntelliJ IDEA**.
3. Run `Main.java` from the `src` folder.
